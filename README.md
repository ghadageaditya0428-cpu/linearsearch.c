# Linear Search in C

This project contains a simple implementation of the **Linear Search algorithm** using the C programming language.

## 📌 About the Project

Linear Search is a simple searching algorithm that checks each element of an array one by one until the target element is found or the entire array has been searched.

## 💻 Language

* C

## 🔍 Example

Given the array:

```text
10 20 30 40 50
```

Target element:

```text
30
```

Output:

```text
Element found at index 2
```

## ⚙️ How It Works

1. Start searching from the first element of the array.
2. Compare each element with the target value.
3. If the element matches the target, return its index.
4. If the target is not found after checking all elements, return `-1`.

## ⏱️ Time Complexity

* **Best Case:** O(1)
* **Average Case:** O(n)
* **Worst Case:** O(n)

## 💾 Space Complexity

* **O(1)**

## ▶️ How to Run

Compile the program using GCC:

```bash
gcc linear_search.c -o linear_search
```

Run the program:

```bash
./linear_search
```
